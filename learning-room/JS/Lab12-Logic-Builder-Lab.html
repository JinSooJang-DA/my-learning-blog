로직 4단계 공식
1. 목표:무엇을 하고 싶은가? (추가? 삭제? 토글?)
2. 필요:뭐가 필요한가? (입력값? 번호? 전체 배열?)
3. 순서:어떤 순서로? (가져오기 → 가공 → 저장 → 그리기)
4. 코드:어떤 함수/문법? (push/splice/!/?)

💡 자주 틀리는 패턴
• Ref vs Value: getElementById는 태그, .value가 글자
• ${i} 빼먹음: 백틱 안에서 숫자 변환 안 하면 문자 i 들어감
• ! 빼먹음: liked = !liked 해야 토글, liked = liked 하면 그대로
• save + render 빼먹음: 배열 바꾸고 저장+그리기 꼭 해야 화면에 보임
