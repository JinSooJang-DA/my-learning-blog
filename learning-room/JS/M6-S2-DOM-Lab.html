04강 – .classList mit add, remove und toggle

JS로 CSS 클래스 class를 추가(add), 삭제(remove), 스위치처럼 껐다 켜기(toggle)하여 디자인을 동적으로 바꾸는 핵심 문법.

.classList.add('클래스명') : 추가 (예: 녹색 배경 켜기) .classList.remove('클래스명') : 제거 (끄기) .classList.toggle('클래스명') : 없으면 추가, 있으면 제거 (스위치/다크모드 원리)
test_div
CSS: .green_bg { background-color: green; ... } HTML: <div class="green_bg" id="test_div"> 처럼 직접 클래스 부여하면 초록 상자 보임 JS: class="green_bg" 지운 뒤 JS로 위 명령 실행

05강 – setAttribute und value

입력창 input에 사용자가 입력한 값을 읽거나 수정하는 .value와, HTML 태그의 속성(type,id,src 등)을 강제로 설정/변경하는 .setAttribute()

.value : <input> 값 읽기/쓰기 읽기: document.getElementById('input_id').value → 현재 입력값 가져오기 쓰기: document.getElementById('input_id').value = 10 → 10으로 바꾸기 .setAttribute('속성명','값') : 속성 강제 지정/변경 예: input.setAttribute('type','password') → 일반 입력창을 *** 비밀번호창으로 변경

중요 비교: classList.add vs setAttribute("class")

이미 <div class="box">가 있을 때: classList.add("test") → class="box test" (유지+추가) setAttribute("class","test") → class="test" (기존 box 날아감! 덮어쓰기)

07강 – onclick → auf Events im DOM/HTML reagieren

버튼 클릭 시 JS 함수 실행, 특정 요소의 클래스 d_none을 껐다 켜서 글자를 보였다 안 보였다(숨김/표시)하는 이벤트 제어.

display: none; ( .d_none 클래스): 화면에서 완전히 숨김 onclick="함수명('파라미터')" : 클릭하면 지정한 JS 함수 즉시 호출 classList.toggle('d_none') : id 요소에 d_none 없으면 붙여서 숨기고, 있으면 떼서 다시 보여줌

ich bin das p tag – 나는 p 태그

08강 – onclick-Alternativen (onchange, onkeydown usw.)

클릭뿐만 아니라 페이지 로딩 completed (onload), 체크박스/입력값 변경 (onchange), 키보드 눌림 (onkeydown) 등 다양한 유저 행동(이벤트)을 감지하는 대체 이벤트 속성들.

onload="..." : 웹페이지가 완전히 열리고(로드되고) 나면 자동 즉시 실행. 보통 <body onload="...">에 사용 onchange="..." : 체크박스 체크/해제하거나, 입력창 내용 바뀌고 포커스 벗어날 때 실행 onkeydown="..." : 입력창에서 키보드 자판 누르는 순간 즉시 실행

① onload 시뮬레이션: 이 페이지는 로드되자마자 콘솔에 123이 찍힙니다.

<body onload="console.log(123)"> → 페이지 열리자마자 123 <input type="checkbox" onchange="console.log(9)"> → 체크할 때마다 9 onkeydown vs onkeyup: keydown은 value 반영 전, keyup은 반영 후

10강 – addEventListener (실무 정석 방식)

HTML 태그 안에 onclick="..."을 직접 적는 대신, 자바스크립트 쪽에서 HTML 요소를 감시(귀를 기울임)하다가 이벤트 발생하면 지정한 함수 실행시키는 실무 정석 방식.

문법: 요소.addEventListener('이벤트종류', 실행할함수이름) 특징: - HTML에는 아무런 이벤트 속성(onclick 등) 적지 않아도 됨 (HTML과 JS의 완벽한 분리) - 두 번째 인자로 전달하는 함수 이름 뒤에는 소괄호 ()를 붙이지 않습니다 (logger O / logger() X) 소괄호 붙이면 클릭할 때가 아니라 코드가 읽히는 순간 바로 실행되어 버림

첫 번째 이미지 (HTML) <h1 onclick="console.log(1)" ...> - 기존 방식 (클릭하면 1)

두 번째 - our_p_tag에 addEventListener로 연결됨 (클릭하면 55555)

document.getElementById("our_p_tag").addEventListener("click", logger); → our_p_tag라는 ID를 가진 <p> 태그를 누르면(click), JS의 logger() 함수가 호출되어 콘솔에 55555 출력 logger vs logger(): logger → 함수 자체를 전달 (클릭할 때 실행) logger() → 지금 당장 실행한 결과를 전달 (페이지 로드시 바로 실행됨, 버그!)
