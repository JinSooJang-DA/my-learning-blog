DECISION TREE / 언제 뭘 쓸까?
1. .value — 입력창 속 진짜 글자
input 태그 전체가 아니라, 사용자가 타이핑한 문자열을 뽑을 때
let input = document.getElementById("todo");
let text = input.value; // "장보기"
todos.push(text);
→ Ref에서 Value 꺼내기
2. i — 순수 JS에서 숫자 변수
for문, 함수 안에서 순번을 다룰 때. 백틱 밖
for(let i=0; i<todos.length; i++){
  console.log(todos[i]);
}
function deleteTodo(i){
  todos.splice(i,1);
}
3. ${i} — 백틱 HTML 안에 숫자 끼우기
백틱(` `)으로 HTML 만들 때 진짜 숫자로 변환 
// ❌ 문자 'i'가 들어감
`
변수 이름 짓는 법
Ref: DOM 자체 → const outputRef = document.getElementById(...)
Value: 꺼낸 값 → const text = input.value.trim()
Index: 순번 → i, bookIndex, commentIndex
HTML: 누적 문자열 → let html = ''; html += ...
