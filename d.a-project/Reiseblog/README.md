# Reiseblog - Exam Website Bootcamp

A responsive travel blog website created as a **group exam project** during the **Frontend Web Developer Bootcamp at Developer Akademie**.

The project was developed as part of the bootcamp to practice and demonstrate fundamental frontend development skills using HTML and CSS.

## About the Project

The Reiseblog is a static travel website consisting of multiple travel-related pages and content sections.

The focus of the project was on:

* Responsive web design
* Semantic HTML structure
* CSS styling and layouts
* Working collaboratively on a shared frontend project
* Creating reusable and consistent design elements
* Adapting content for different screen sizes

## Features

The project includes:

* Responsive page layouts
* Travel article pages
* Navigation elements
* Image and content sections
* Travel destinations and recommendations
* Travel tips and suggested itineraries
* CSS-based interactive elements
* Embedded media
* Social sharing elements
* Footer and social media links

## Technologies

* **HTML5**
* **CSS3**
* **Visual Studio Code**

No JavaScript framework, frontend library, or backend was used.

## Project Structure

```text
Reiseblog-DA-Test/
├── assets/
├── styles/
├── index.html
├── Neelima_Index.html
├── Patrick.html
├── jin-seite01.html
└── style.css
```

The `assets` directory contains the images and icons used throughout the website, while shared styles are organized inside the `styles` directory and the main stylesheet.

## Running the Project

No installation or build process is required.

Clone the repository:

```bash
git clone https://github.com/PatrickWagnerDev/Reiseblog-DA-Test.git
```

Open the project folder in Visual Studio Code and open the desired HTML file directly in your browser.

Alternatively, a local development extension such as **Live Server** can be used.
